# 答辩前检查清单

本清单用于答辩前 1 天和答辩当天快速自检，避免出现“代码能跑但现场演示卡住”的情况。

---

## 一、环境检查

- [ ] 当前使用的 Python 版本与项目依赖兼容。
- [ ] 已执行 `pip install -r requirements.txt`。
- [ ] `.env` 已配置且 API Key 可用。
- [ ] Neo4j 已启动，连接信息与 `.env` 中配置一致。
- [ ] 若准备展示 LangGraph 可视化，相关依赖已在本机可用。

建议现场先确认：

```bash
python -m src.cli list-commands
python -m src.cli demo-guide
```

---

## 二、输入与资源检查

- [ ] 项目根目录存在 `王佛脱险记.txt`。
- [ ] 如需展示第二文本验证，已准备好 `docs/validation_samples/马尔戈的微笑.txt` 或其他样例。
- [ ] `assets/` 中立绘、背景图、音乐资源路径完整。
- [ ] `wangfo/game/images/` 下背景图与角色资源未丢失。

---

## 三、生成产物检查

### 1. 最终游戏工程

- [ ] `wangfo/game/script.rpy` 存在且入口正常。
- [ ] `wangfo/game/characters.rpy` 已生成。
- [ ] `wangfo/game/paths/` 下存在主线路径和分支路径脚本。
- [ ] `wangfo/game/endings/` 下存在结局脚本。

### 2. 中间产物

如果准备展示完整流水线，答辩前应确认以下产物存在：

- [ ] `out/extract_chain.json`
- [ ] `out/entities.json`
- [ ] `out/state_baseline.json`
- [ ] `out/canonical_branch.json`
- [ ] `out/decision_points_analysis.json`
- [ ] `out/branches.json`
- [ ] `out/all_paths_completed/`
- [ ] `out/enhanced_paths/`

建议在项目根目录执行：

```bash
python -m src.cli validate-outputs --mode all
```

若现场只展示最终游戏，可执行：

```bash
python -m src.cli validate-outputs --mode game
```

---

## 四、演示材料检查

- [ ] `docs/DEMO_SCRIPT.md` 已按自己的口播习惯通读一遍。
- [ ] `docs/答辩实验结果.md` 中的数字与当前工程一致。
- [ ] 论文 `docs/thesis.md` 与 `docs/论文素材.md` 中的实验数字已统一。
- [ ] 已准备好 1 条主线展示点和 1 个分支展示点。
- [ ] 已准备好至少 3 张截图或 1 段录屏。

推荐截图：

- 游戏启动界面
- 典型剧情画面
- 菜单选择画面
- 结局画面
- CLI 或 Neo4j 展示画面

---

## 五、现场演示顺序检查

- [ ] 先打开游戏，控制在 1 到 2 分钟内展示成果。
- [ ] 再展示 `python -m src.cli demo-guide`。
- [ ] 如老师追问，再进入 `python -m src.cli demo` 的完整步骤。
- [ ] 中间产物只展示 2 到 3 个文件，不展开所有 JSON。
- [ ] 结尾用 `docs/答辩实验结果.md` 的统计表收尾。

---

## 六、风险预案

### 1. 网络不可用

- [ ] 已准备录屏版本，能在无法调用外部 API 时展示完整流程。
- [ ] 已准备最终生成好的 `wangfo/` 游戏工程。

### 2. `out/` 产物不完整

- [ ] 至少保证 `wangfo/game/` 可正常运行。
- [ ] 中间产物若不全，优先展示已有的结构化结果和脚本产物。

### 3. 老师追问“如何验证”

- [ ] 能说明四类最小测试：全链路烟雾、结构校验、Ren'Py 可运行性、第二文本轻量验证。
- [ ] 能指出对应命令：`validate-outputs`、`collect-metrics`、第二文本抽取脚本。

---

## 七、答辩当天最后 5 分钟

1. 打开项目根目录终端。
2. 运行 `python -m src.cli demo-guide` 确认命令可用。
3. 打开 Ren'Py Launcher，确认 `wangfo/` 能正常启动。
4. 打开 `docs/DEMO_SCRIPT.md` 与 `docs/答辩实验结果.md` 备用。
5. 确认录屏文件、截图文件、论文 PDF 均可快速打开。
