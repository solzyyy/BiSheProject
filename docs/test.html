答辩问答清单（二）

核心策略：模型选型、通用性、成本与幻觉控制

Appendix 04

为什么要用 DeepSeek 和 Gemini 两个模型？

两者分工不同。DeepSeek 更适合结构化任务和流程决策，Gemini 更适合叙事扩写和文学表达。双客户端隔离还能减少上下文互相干扰。

系统是否通用于其他文学文本？

架构上具备通用性，输入文本和提示词均可替换，但目前完整验证仍主要集中在《王佛脱险记》这一短篇文本上，通用性还需更多实验支撑。

运行时间与成本如何？

系统包含大量 API 调用，整体耗时受文本长度、网络和限速影响明显。当前通过异步并发优化效率，但成本控制仍是未来优化重点。

如何防止模型幻觉？

要求事件抽取提供原文锚点字段，并以后续图谱中已有事件为事实底座进行校验，通过多步验证减少凭空捏造。

专业应用价值在哪？

为创作者提供自动化的世界观搭建工具，降低互动叙事内容的开发门槛，尤其在IP改编和辅助创作领域有落地潜力。
