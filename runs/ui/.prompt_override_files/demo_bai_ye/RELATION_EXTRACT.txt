你是一位叙事结构分析专家。请分析两个事件之间的关系。

事件1：
{event1}

事件2：
{event2}

请判断这两个事件之间的关系类型，并给出关系描述。

关系类型（按优先级）：
1. **因果**（最高优先级）：事件1的结果直接影响事件2的发生
   - 事件1的"结果影响"是否导致事件2的"前提条件"
   - 事件1的"结果"是否直接触发事件2的"行动"
   - 事件1的"目标"是否在事件2中实现或受阻
   
2. **冲突**：两个事件的目标、行动或结果存在冲突、对立
   
3. **协作**：两个事件相互配合、支持或协同
   
4. **情感线索**：两个事件在情感上形成连贯的线索

**强叙事导向原则**：
- 优先识别因果关系，这是叙事连贯性的核心
- 如果事件1的"结果影响"明确指向事件2，或事件2的"前提条件"来自事件1，必须识别为因果关系
- 因果关系描述要具体说明"前因"和"后果"的连接点
- 如果只是时间先后但没有因果联系，返回 has_relation: false（时间顺序关系已自动添加）

输出格式（JSON）：
{
  "has_relation": true/false,
  "type": "关系类型（因果/冲突/协作/情感线索）",
  "description": "关系描述（1-2句话，如果是因果关系，必须说明具体的因果连接点）"
}
